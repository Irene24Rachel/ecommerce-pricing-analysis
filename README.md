# E-Commerce Pricing Analysis

A data analysis project exploring pricing, discounts, brands, and product
patterns in an e-commerce women's fashion dataset.

## 📌 Project Overview

This project analyzes an e-commerce product catalog to understand pricing
strategies, discount patterns, brand positioning, and product-level
characteristics.

The analysis uses Python and data visualization techniques to identify
patterns that can provide useful business insights.

## 🎯 Objectives

- Analyze product pricing patterns
- Explore discount strategies
- Compare brands and price ranges
- Analyze product categories
- Identify relationships between retail and sale prices
- Understand discount distribution
- Generate actionable business insights

## 📊 Dataset

The project uses an e-commerce women's fashion product dataset.

The dataset contains information related to products, brands, pricing,
discounts, and product categories.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
